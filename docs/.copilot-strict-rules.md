# 🤖 Copilot Strict Rules

> **Versão:** 1.0.0
> **Data:** 11 de dezembro de 2025
> **Escopo:** Enterprise Database Migration System

## 🎯 Objetivo

Definem regras **estritas** para manter a qualidade, consistência e organização do código ao trabalhar com GitHub Copilot. Evitam duplicação, garantem padrões e melhoram a eficiência.

## 📁 REGRA 1: Organização de Arquivos

### ✅ OBRIGATÓRIO

**Cada tipo de arquivo deve ser salvo em sua pasta específica:**

```
app/            → Código principal da aplicação
  ├── core/       → Lógica de migração
  ├── cleanup/    → Limpeza de dados
  └── validation/ → Validação de dados

cli/            → Scripts e interfaces CLI
  └── run_migration.py → Entry point principal

components/     → Componentes reutilizáveis
  ├── base_component.py → Base abstrata
  ├── config_manager.py → Gerenciamento config
  └── config_normalizer.py → Normalização config

orchestrators/  → Orquestradores de processo
  ├── migration_orchestrator.py
  └── orchestrator_pure_python.py

validation/     → Validadores e verificadores
  ├── verify_*.py → Scripts de verificação
  └── *_validator.py → Classes validadoras

config/         → Arquivos de configuração
  ├── *.json     → Configurações estruturadas
  ├── *.yaml     → Configurações YAML
  └── templates/ → Templates

scripts/        → Scripts shell e automação
  ├── *.sh     → Scripts shell
  └── *.bash   → Scripts bash

docs/           → Documentação
  ├── *.md     → Documentação Markdown
  ├── SESSION_REPORT_*.md → Relatórios de sessão
  └── STATUS_*.md → Status do sistema

secrets/        → Configurações sensíveis (GIT-IGNORED)
  ├── *_config.json
  └── *_secrets.json

tools/          → Utilitários operacionais de uso frequente (2026-02-19)
  ├── README.md           → Documentação das ferramentas
  ├── Makefile            → Atalhos de execução
  ├── migrate_users/      → Scripts de migração de usuários
  └── fix_permissions/    → Scripts de correção de permissões

utils/          → Funções utilitárias
  ├── *_util.py → Utilitários diversos
  └── *_helper.py → Funções auxiliares

test/           → Testes unitários
  ├── test_*.py → Testes
  └── analise_*.py → Scripts análise
```

### ❌ PROIBIDO

- **Não** criar arquivos Python na raiz do projeto
- **Não** deixar scripts de teste soltos na raiz
- **Não** criar subdiretorios adicionais sem aprovação
- **Não** misturar tipos de arquivo em pastas erradas

### 📋 Exemplo de Violação (CORRIGIR)

```
❌ ERRADO (na raiz):
- user_migration.py → Deve estar em: app/core/user_migration.py
- my_validator.py → Deve estar em: validation/my_validator.py
- util_functions.py → Deve estar em: utils/util_functions.py

✅ CORRETO:
- app/core/user_migration.py
- validation/my_validator.py
- utils/util_functions.py
```

#### Arquivo CLI

# ✅ CORRETO - cli/run_migration.py

"""Interface CLI para migração."""

import argparse
import logging
import sys
from pathlib import Path

from app.core.migration import DatabaseMigrator
from components.config_manager import ConfigManager

logger = logging.getLogger(__name__)


def main():
    """Função principal CLI."""
    parser = argparse.ArgumentParser(
        description="Executa migração de banco de dados"
    )
    parser.add_argument(
        "--dry-run",
        action="store_true",
        help="Executar sem fazer alterações"
    )
    parser.add_argument(
        "--verbose",
        action="store_true",
        help="Modo verbose"
    )

    args = parser.parse_args()

    try:
        config = ConfigManager().load()
        migrator = DatabaseMigrator(config)
        result = migrator.run(dry_run=args.dry_run)
        sys.exit(0 if result.get('success') else 1)
    except Exception as e:
        logger.error(f"Erro: {str(e)}", exc_info=True)
        sys.exit(1)


if __name__ == "__main__":
    main()

# ❌ ERRADO

# ✅ CORRETO - test/analyze_migration.py

"""Script para análise de resultados de migração."""

import json
import logging
from pathlib import Path
from typing import Dict, Any

logger = logging.getLogger(__name__)


def analyze_results(report_path: str) -> Dict[str, Any]:
    """Analisa resultados de migração.

    Args:
        report_path: Caminho do relatório JSON

    Returns:
        Dict com análise
    """
    with open(report_path, 'r') as f:
        data = json.load(f)

    # Análise
    analysis = {
        'total': len(data),
        'success': sum(1 for x in data if x.get('success')),
        'failed': sum(1 for x in data if not x.get('success')),
    }

    logger.info(f"Análise concluída: {analysis}")
    return analysis


if __name__ == "__main__":
    result = analyze_results("reports/migration_20251211.json")
    print(json.dumps(result, indent=2))
